# Code of Conduct

SoroCron is built by contributors from many backgrounds and experience levels. We want every one of them to feel welcome.

## Expected behaviour

- Be respectful and assume good faith.
- Review code, not people. Explain the *why* behind change requests.
- Be patient with newcomers; everyone's first Soroban PR is hard.
- Credit others' work and ideas.

## Unacceptable behaviour

- Harassment, insults, or discriminatory language of any kind
- Personal or political attacks
- Publishing others' private information
- Spamming issues or PRs, including low-effort submissions made only to claim rewards
- Pressuring maintainers or contributors for assignment, merges, or payouts

## Enforcement

Maintainers may edit or remove comments, close issues or PRs, unassign contributors, or block accounts that violate this code. Serious or repeated violations may be reported to program organisers where applicable (for example, Drips Wave).

Report concerns privately to the maintainers through the organisation's GitHub contact, or via a private security advisory if a public report isn't appropriate.
